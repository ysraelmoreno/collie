Quatro jeitos de reorganizar o Collie

O Trilho atual põe tudo no mesmo canvas: cercados, agentes, painéis, laços e memória disputam o mesmo espaço, e boa parte das funções só aparece pelo ⌘K ou por comando. Cada modelo abaixo parte de uma pergunta diferente sobre como você trabalha. Abra, clique e use o botão “Notas de UX” de cada um para ver onde cada uma das 17 funções foi parar.

A

Conversa

Você fala com um Pastor, como num chat. Agentes convocados viram sub-fios dentro da conversa, o painel que o agente está usando aparece sozinho à direita, e cartões de sandbox chegam inline para aprovar ali mesmo.

Para quem delega: descreve o objetivo e acompanha o resultado.

Abrir → B

Estúdio

Um ambiente tipo IDE: terminais e painéis em blocos com abas e divisões, uma barra de atividade com um ícone fixo para cada função e uma gaveta de Atividade com eventos e pedidos pendentes.

Para quem põe a mão na massa: vê vários agentes e painéis ao mesmo tempo, organizado.

Abrir → C

Torre de controle

A tela inicial mostra tudo que está rodando: “Precisa de você” no topo e um quadro com uma coluna por cercado e um cartão por agente. Clicar num agente entra no modo Foco; Esc volta.

Para quem orquestra muitos agentes em vários cercados.

Abrir → D

Canvas organizado

O canvas continua sendo a tela principal, mas cada cercado vira uma moldura nomeada, o zoom afastado mostra cartões de estado e o próximo mostra o terminal real. Painéis ficam presos ao agente que os usa, e o inspetor só aparece com algo selecionado.

Para quem gosta do canvas espacial e quer ordem sem perdê-lo.
