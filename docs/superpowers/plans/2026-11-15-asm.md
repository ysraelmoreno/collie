# ASM (Active Shared Memory) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-deployable server holding shared memory spaces with per-space access, and a Collie client that mirrors
the spaces a repo is bound to over SSE, injects them in prompts, and writes to them — up to the pilot (spec phases 0–5).

**Architecture:** New Swift package `ASM/` with two products: `CollieSpaceWire` (Foundation-only wire types, scrub,
SSE parser, lifecycle rules; Linux + macOS) and `asm-server` (Hummingbird 2 + PostgresNIO). The root package depends on
`ASM/` by path for `CollieSpaceWire` only. The daemon gets a `Spaces/` folder: logins, repo binding, `SpaceSync` actor
(snapshot + SSE + outbox), a mirror store per space, and a new `MemoryScope.space` wired into ranking/injection.

**Tech Stack:** Swift 6.2, Hummingbird 2, PostgresNIO, Postgres 16, swift-crypto (server, Ed25519), CryptoKit (daemon),
URLSession `bytes(for:)`, swift-testing, Docker.

**Spec:** `docs/superpowers/specs/2026-11-15-asm-design.md` (read it first, including "Decisions after the builder
check").

## Global Constraints

- Root targets `collied`, `collie`, `CollieApp` link `CollieSpaceWire` only — never Hummingbird/PostgresNIO.
- `CollieSpaceWire` imports Foundation only (no CryptoKit, Darwin, AppKit, Network); builds in `swift:6.2` on Linux.
- Pin every new dependency `exact:` (like SwiftTerm).
- Tests: only changed/created tests via `--filter`, never the full suite.
  Root: `swift test --scratch-path .build/Collie-Main --filter <Name>`. Server: `swift test --package-path ASM --filter <Name>`.
  DB tests skip unless `ASM_TEST_DATABASE_URL` is set (`docker compose -f ASM/docker-compose.yml up -d db`).
- Space body ≤ 4096 bytes UTF-8. Allowed kinds: `decision`, `pitfall` (no `hits`), `feedback`, `procedure`. `map` rejected.
- Hooks never touch the network: prompt/session paths read the mirror only.
- Mirror and logins: 0700 dirs / 0600 files under `<root>/spaces/` (`MemoryStore(secureRoot:)`).
- Lifecycle numbers: earned = ≥ 2 distinct users on ≥ 2 distinct days; longTerm = ≥ 4 distinct users spanning ≥ 14 days
  (or admin pin); 1 `wrong|outdated` → contested; 2 distinct users → archived; provisional unused 30 days → archived.
- Supersede by any writer acts at once; old author or admin can restore.
- Invisible means 404, never 403, for spaces the caller cannot read.
- SSE: `id:` = event seq, `Last-Event-ID` resume, heartbeat `: ping` every 25 s, first event `spaces`, `resync` on gap.
- Client reconnect backoff 1 s doubling to 60 s.
- Commits: one per task, only that task's files, trailer `Co-Authored-By:` as instructed by the session. No push.

## Review Focus

1. **Repo points to a server the user never logged into** (or same URL, different key) → nothing is fetched or sent; a
   pending binding is listed. Test in Task 11.
2. **Access revoked while a Mac is offline** → on next connect the `spaces` event lacks the slug and the mirror, its
   index rows and its outbox entries are deleted. Test in Task 12.
3. **Server down during a prompt** → injection returns mirror content with no added latency. Test in Task 13.
4. **Secret in a candidate** (`ghp_…`, `AKIA…`, `/Users/<name>/…`, an email) → removed before the outbox *and* rejected
   or scrubbed by the server. Tests in Tasks 2 and 5.
5. **Two Macs of the same user flag one memory** → counts as one user: contested, not archived. Test in Task 7.

### Task 6: SSE stream with LISTEN/NOTIFY fan-out

**Files:**

**Interfaces — Produces:**
