# Idiomas (inglês primeiro) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App, daemon e CLI falam português ou inglês conforme Preferências › Interface › "Idioma" (Sistema/Português/English).

**Architecture:** Uma função `tr(_ pt:, _ en:)` em CollieCore escolhe o texto pelo idioma ativo do processo. O idioma
fica em `CollieSettings.language` (`preferences.json`); o daemon o atualiza ao vivo via `admin.language` e o injeta em
cada terminal como `COLLIE_LANG`; a CLI lê `COLLIE_LANG` → arquivo → sistema; o app lê cópia em `UserDefaults` no início
e reinicia ao trocar.

**Tech Stack:** Swift 6, SwiftPM, SwiftUI, swift-testing, `Synchronization.Mutex`, `@TaskLocal`.

**Spec:** `docs/superpowers/specs/2026-11-26-idiomas-design.md`

**Desvio do spec (decisão do agente, para o dono confirmar na revisão do plano):** o spec fala em "chave tipada" numa
tabela por área. O plano usa os dois textos lado a lado no ponto de uso: `tr("Cercado \(n) apagado", "Paddock \(n) deleted")`.
Mesmo objetivo (os dois idiomas sempre presentes), garantido pelo compilador em vez de um teste, sem inventar ~1.700 nomes
de chave e sem arquivo de tabela que vira ponto de conflito entre agentes. Interpolação continua inteira em cada idioma,
nunca pedaços concatenados.

## Global Constraints

- Sem `Bundle.module`, sem recursos SwiftPM, sem mudança em `scripts/bundle-app.sh`.
- `language` em `preferences.json` é `String?`, valores `system|pt|en`; nil ou desconhecido = `system`.
- `system`: `Locale.preferredLanguages.first` começa com `pt` → pt; senão → en.
- Descrições MCP e `summary:` de `Commands.swift` não mudam (já em inglês).
- Dados do usuário (memórias, nomes, temas, planos) nunca traduzidos. Texto que o Collie grava (commits, land, notas,
  eventos) fica no idioma ativo na hora e nunca é reescrito.
- Vocabulário em inglês (CHANGELOG): cercado→paddock, Pastor→Shepherd, coleira→leash, laço→loop, rebanho→herd,
  lote→lot, Pasto→Pasture, field→field, Prévia→Preview, convocar→summon.
- Testes: só os criados/alterados, `swift test --filter <Suite>`; nunca a suíte inteira; sem `--scratch-path` próprio.
- Commit só dos próprios arquivos: `git commit -- <paths>` (índice compartilhado com outros agentes).

## Review Focus

1. `preferences.json` ilegível (fail-closed) ou com `language` desconhecido → segue o sistema, nunca quebra. (Task 2)
2. Terminal aberto antes da troca mantém o idioma antigo; terminal novo pega o novo. (Task 2)
3. Testes antigos que comparam texto em português rodando em máquina com sistema em inglês: precisam forçar `pt`. (Tasks 5–9)
4. Comparação de mensagem por texto (`hasPrefix`/`contains`) quebrando quando o idioma muda entre quem produz e quem
   compara. (Task 4)
5. App aberto sem daemon conectado: idioma vem do `UserDefaults`, não fica em branco nem trava a tela de Preferências. (Task 3)
