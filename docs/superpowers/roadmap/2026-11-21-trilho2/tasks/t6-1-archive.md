# T6.1 Resumo imutável ao fechar o trabalho e `work.history`

Leia `README.md` (esta pasta). Motor. ## Fazer
1. **`WorkArchive`** (tipo `Codable`, `Sendable`, em `CollieCore`): `{version:1, id, title, paddock (nome), branch, terminal, openedAt, closedAt, stopReason (Stop.Code?, tolerante), tasks:[{id,title,state,tries,failure?,commits:[sha],evidenceNote?}], timeline:[{at, task?, kind, detail}], notes:[String] (cauda), loopSummary: String}`. Decodificação **tolerante** (campos novos opcionais; valor desconhecido não derruba), `Codable` de saída estável.
2. **Gravação:** quando o trabalho **fecha** (`work.done`, ou o laço termina e o trabalho já estava fechado) o daemon grava `<raiz>/work-archive/<work-id>.json` **uma única vez** (gravação atômica; se o arquivo existe, **não** sobrescreve; se o trabalho for reaberto e fechado de novo, grava `<id>-<n>.json` com a numeração seguinte). A `timeline` vem do diário do trabalho **no momento do fechamento** mais o que já houver num resumo anterior (sem duplicar), até **500 eventos** (corte pelos mais antigos, com um evento `truncated`). O arquivo nunca passa de **1 MB**.
3. **Retenção:** manter os **200** resumos mais recentes por raiz; ao gravar um novo, apagar os mais antigos além disso (nunca o que acabou de gravar).
4. **`work.history`** (comando novo, protocolo + CLI `collie work history [--limit N] [--id <work>]` + MCP `work_history`): sem `id`, devolve os últimos N (padrão 20, máximo 50, ordem do mais recente para o mais antigo) **só do cercado do chamador** (o app, admin, vê o cercado que pedir via `paddock`); com `id`, devolve o resumo completo daquele trabalho (se for do cercado do chamador). Nunca devolve resumo de outro cercado. Linha de listagem: `{id,title,openedAt,closedAt,stopReason,done,total,deferred,durationSeconds}`.
5. Texto que veio do trabalho vai **como está** nos dados (escapar é problema de quem renderiza, T6.5).
6. Trabalhos fechados **antes** desta tarefa não têm resumo: `work.history` os monta a partir do `Work` guardado (diário de 20, sem `truncated`), marcando `reconstructed: true`.
