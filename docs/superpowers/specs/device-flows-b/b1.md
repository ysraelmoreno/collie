# b1: senha nunca vai para o log (iOS e falha fechada)

Onda b dos fluxos do device (achados 1 e 2 de segurança em `.collie/briefs/rev-device-flows-d1-d7.md`; leia). Check: `scripts/check-device-flows-b.sh b1` (não o altere). Testes sem relógio real nem sleep; só `swift test --filter`.

## O que construir
- iOS: `AXeTree` marca `password: true` para `SecureTextField`, e o valor do nó nunca entra em `desc`/`text` de UINode quando é senha.
- Falha fechada: o `text` de uma ação `device.text` só é gravado em claro quando a última leitura de tela **prova** que o alvo não é campo de senha. Sem leitura (daemon reiniciado, nenhum `device screen`), com `refs` vazio ou com leitura de outra tela (`sigBefore` ≠ tela atual), grava `FlowActionLog.mask`.
## Critérios de aceite (testes em `FlowSecureTests`, ≥ 6)
- iOS: SecureTextField vira nó com `password`; o texto digitado vai mascarado no log.
- Sem leitura prévia, `text` vai mascarado; com leitura de campo comum, em claro (até 80); com leitura obsoleta, mascarado.
- Os testes existentes (`FlowActionRecordingTests`, `FlowActionLogTests`) continuam passando.
