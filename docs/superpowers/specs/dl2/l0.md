# L0: device launch com vários activities de launcher

Bug medido em 2026-11-22: com.abinbev.android.app.br tem 2 activities LAUNCHER (BrowseActivity e leakcanary LeakLauncherActivity). `device launch <pkg>` sem --activity usa monkey, que sai com 251 e não abre nada; a mensagem de erro despeja os args do monkey. Conserto em Sources/CollieDaemonKit/Devices/DeviceService+Android.swift (case device.launch): sem --activity, listar os launchers com `adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER <pkg>`, abrir o primeiro com `am start -n pkg/activity` (se não houver lista, cair no monkey de hoje); a resposta passa a trazer `activity`; erro claro (sem despejar args) se nada abre. A string 'query-activities' deve aparecer no arquivo. Teste com o adb falso dos testes existentes (DeviceCommandTests): 2 launchers abre o primeiro; 1 launcher; lista vazia cai no monkey.

Regras: testes novos com nomes claros, só com --filter; não rode a suíte completa; não edite scripts/; não commite arquivos alheios; uma tarefa por vez.
