# K1b: daemon troca o helper quando a assinatura mudou

Trocar a chave de assinatura (K1) faz adb install -r falhar com INSTALL_FAILED_UPDATE_INCOMPATIBLE em aparelhos que já têm o helper assinado com outra chave. Em DeviceHelper (instalação e a escada de recuperação, passo install -r): se o install falhar com INSTALL_FAILED_UPDATE_INCOMPATIBLE ou INSTALL_FAILED_VERSION_DOWNGRADE, desinstale com.collie.helper (adb uninstall) e instale de novo UMA vez, habilite e confirme com dump com nós; o motivo vai para o device helper status. A palavra UPDATE_INCOMPATIBLE deve aparecer em Sources/CollieDaemonKit/Devices/. Testes DeviceHelperTests com adb falso: install -r falha com o erro, o daemon desinstala e reinstala uma vez, segunda falha cai no fallback com motivo claro, a lista de serviços alheios preservada.
